# cfb-jobs

The scheduled data job for [mycfbbigboard.com](https://mycfbbigboard.com). It gathers public football data, builds the site's shared data files and publishes them to the site. The site itself, its grading model and its users' data are not in this repository.

Runs are started by the site's scheduler, or by hand from the Actions tab. Nothing runs on pull requests.
